## Boundary Convention
- Square brackets `[low, high]` indicate **inclusive** limits (`low <= value <= high`).
- Parentheses `(low, high)` indicate **exclusive** limits (`low < value < high`).
- Age intervals follow the same `[min, max]` or `(min, max)` convention in years. Values `all` apply across all ages or sexes.
